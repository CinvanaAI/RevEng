# Visual assets

RevEng includes 22 PNG interface assets used by the agent and capability environments.

The public-repository preparation pass checked the files for embedded image metadata. No EXIF, GPS, author, prompt, username, or free-text metadata was present; three files contain only standard PNG color-space metadata (`gamma` and `srgb`).

The visual assets are distributed with RevEng under the repository's MIT License. The historical workspace did not include a separate third-party asset license or provenance ledger.
